Layout decisions
Atlas tab placement
Added after CIG (7th tab). Uses cloud_sync icon. Tab label: "Atlas".
Mode toggle
Pill toggle — Single SI / Excel Upload. Matches existing sub-tab pattern in sidepanel.js:87.
TCIS dropdown override
In Excel mode, dropdown has a "— select —" blank option. If set, it overrides all per-row values. If left blank, per-row Excel column B is used.
Excel template columns
Column A — SI Number
Required. Format: SI-XXXXXXXXX. Validated on parse — invalid format rows are flagged inline.
Column B — Test Central In-Scope
Enter Yes or No (case-insensitive). Used unless global dropdown overrides.
Column C — Notes
Optional. Free text, ignored by updater. Useful for tracking who requested the change.
Results table states
✓ OK (green)
PATCH returned HTTP 204. Read-back confirmed expected value.
✗ Not found (red)
No GUID returned for SI number. Skipped, remaining rows continue.
⚠ Auth error (amber)
HTTP 401. Message: "Open Atlas tab first to authenticate."
Safety guards
Confirm dialog
Always shown before execution. Shows count + target value. Cannot be suppressed.
Run button disabled state
Disabled until: SI input is non-empty (or file parsed) AND TCIS dropdown is set.
Auth model
Kerberos via browser
fetch(url, {credentials:"include"}) — browser handles Negotiate auth automatically. No token, no OAuth. Requires Atlas tab open in same Chrome profile.
